name: task-brief
description: Emit a task brief — objective, scope, out-of-scope, exit criteria, blockers — before starting implementation
---
Before starting implementation emit a task brief with these fields: Objective one sentence, Scope list of files to modify with what changes, Out of scope list of files not touching with reason, Exit criteria checklist including no stubs remaining and memory cascade written and conventional commit staged, Blockers list of unresolved OQs or gate conditions. If approval is required stop after emitting and wait for approved proceed.
