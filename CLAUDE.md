# Claude Entry Point

`AGENTS.md` is the primary instruction file for this repository.

## Required Read Order

1. Read `AGENTS.md` first.
2. If you are working inside a subdirectory, read the nearest local `AGENTS.md` in that subtree as well.
3. Then use `docs/INDEX.md` as the entrypoint into the live documentation set.
4. Use `docs/specs/SPEC_DRIVEN_DEVELOPMENT.md` and `docs/plans/ROADMAP.md` for process and current-state context.

## Claude-Specific Notes

- There are no separate Claude-only workflow rules at the moment.
- Do not duplicate repository instructions here. Add Claude-only guidance only if it cannot live cleanly in `AGENTS.md`.
